# 篮球场：原图误差复核与第三片段内参迁移

日期：2026-09-22。接续[两个连续片段的局部 SfM](basketball_local_sfm.md)。本轮实际完成原图样例复核、第三片段 145–169 的固定内参对照，以及两项补充诊断。

**候选内参在新的 50 张图像上仍有收益，R 镜头的 `cy` 是值得继续优化的参数；但原始轨迹中存在错配、遮挡与定位歧义，当前结果仍不足以认定全场满足高一致性 3DGS 的要求。简单的原图角点精化没有取得明确收益，未加入默认流程。**

## 原图复核：大误差不全是内参误差

复核覆盖两段、L/R、中心/中圈/外圈，刻意选择较大误差、低误差对照和原始长轨迹尾部，共 44 例。它是诊断抽样，不能用于估计整批数据的错误率。每例显示两个留出支持点和一个留出查询点；绿色为 LoMa 观测、黄色为固定初始内参的预测、红色为主点优化后的预测。

可见的具体问题包括：

- [case 043](../work/basketball/residual_audit/index.html#case_043)：建筑屋顶/窗线与树木轮廓被串入同一条原始轨迹，是清楚的实体对应问题。
- [case 017](../work/basketball/residual_audit/index.html#case_017)：即使三条直接匹配置信度均高，树木轮廓与后方窗线的交会也随视角变化，不能直接当作固定三维点。
- [case 019](../work/basketball/residual_audit/index.html#case_019)、[case 020](../work/basketball/residual_audit/index.html#case_020)、[case 022](../work/basketball/residual_audit/index.html#case_022)：屋顶立柱、栅格等重复结构使长轨迹串接不可靠。
- [case 013](../work/basketball/residual_audit/index.html#case_013)：同一外墙结构附近，LoMa 点并不恰好落在清楚的交点上；弱纹理墙面、玻璃、粗球场线也有定位歧义。仅凭目视无法将所有误差定量分解成特征定位和相机几何两部分。

也保留了较清楚的静态结构低误差对照和低误差植被样例。低重投影误差本身不能证明匹配正确。全部说明见 [annotations.json](../work/basketball/residual_audit/annotations.json)；它们是辅助目视判断，没有充当标注真值或修改观测。

因此不能把这些误差全部解释成鱼眼标定错误、异步曝光或滚动快门，也不应通过重新大面积删除植被来掩盖轨迹问题。当前证据支持优先检查跨视图对应是否指向同一个稳定物理位置。

## 第三片段：先锁定规则，再比较候选内参

新片段为帧 145–169，共 25 张 L 和 25 张 R，与前两段图像不重叠。选择时查看了建筑、篮架、灯杆及屋顶等结构覆盖，没有根据本段优化结果挑选片段。拟合前保存了三组完整内参快照、特征参数、掩码版本和留出规则，见 [protocol.json](../work/basketball/transfer_sfm/protocol.json)。

三组参数分别为 `.pro` 初值、70–94 的最终候选、190–214 的最终候选。先用初始内参建立一份训练重建，再复制同一组点及观测；每组内参全程固定，仅优化每张图独立的位姿与三维点。没有同步曝光或固定 L/R 外参约束。输入 pose 只用于按同名记录决定图像是否入选，其数值与 LAS 均不参与拟合。

使用与上一轮相同的 LoMa-B、修正版 mask 和初始 160° 有效域，三组候选使用完全相同的特征及匹配。新片段 FOV 内 mask 保留面积为 81.2%–93.6%，中位数 87.5%；这不是分割准确率。50 份特征及 357 对匹配在本轮实际计算。

完整原始轨迹在任何几何拟合前留出，并移除所有接触留出观测的训练边。高置信子集要求两个支持观测与查询观测之间的三个直接 LoMa 匹配置信度均 ≥0.9；本段在几何计算前就锁定该规则及查询清单，没有按查询误差挑点。

验证以两个留出支持观测三角化，再预测其他留出观测。相机位姿由同一批图像的其他特征估计，因此这属于观测留出；第三段没有参与候选内参估计，但它不是独立采集的标定真值。共同训练拓扑还依赖初始内参下的注册/筛选，这也是比较的条件。

## 补充诊断一：R 的 cy 起了多大作用

在看到主要迁移结果后，追加两组固定内参对照：仅将初始 R 的 `cy` 从 1990.5075 改为 2003.52238677，即 +13.01488677 px；以及使用完整 70–94 候选，但把 R 的 `cy` 恢复为初值。四组仍使用相同训练拓扑、相同留出点，各自优化位姿与三维点。

| 参数组合 | 全部 1,488 查询 median / P90 | 共同 1,349 查询 median / P90 |
|---|---:|---:|
| 全部初值 | 1.646 / 5.805 | 1.574 / 4.505 |
| 仅修改 R cy | 1.537 / 4.707 | 1.438 / 3.961 |
| 完整 70–94 候选 | 1.542 / 4.567 | 1.435 / 3.981 |
| 完整候选，但撤回 R cy | 1.661 / 5.663 | 1.587 / 4.463 |

仅修改 R `cy` 能复现大部分改善；撤回这项修改后，完整候选的大部分优势也消失。因此把 R `cy` 作为下一阶段重点优化参数有依据。**不能据此认定 +13 px 为真实标定改正数**：这是同一采集、同一第三段上的解释性诊断，包含匹配、位姿/点优化及数值停止条件的影响。两项新增对照是在主要结果之后提出，没有增加一个新的独立验收集。

## 补充诊断二：原图角点精化没有明确收益

针对可见的特征定位歧义，在 70–94 上做一次有界试验。使用 [OpenCV 角点函数](https://docs.opencv.org/4.13.0/dd/d1a/group__imgproc__feature.html)的原图灰度梯度，仅精化已经进入训练的二维观测，不使用相机预测位置作为目标。要求两次扰动初值得到的位置相差 ≤0.25 px、改动 ≤3 px、角点响应足够且仍在有效域内。保留未通过条件的原始坐标，不删点。

固定同一组候选内参、15,227 个点和 55,754 个观测，接受精化 12,876 个观测（23.1%），接受位移中位数 1.676 px、P90 为 2.735 px。所有留出支持点及查询点保持原始 LoMa 坐标；两组只重新优化姿态与三维点。

| 训练观测 | 全部 832 高置信查询 median / P90 | 共同 774 查询 median / P90 | 共同查询 ≤2 px |
|---|---:|---:|---:|
| 原始 LoMa | 1.644 / 5.455 | 1.547 / 4.633 | 62.4% |
| 接受局部角点精化 | 1.640 / 5.381 | 1.547 / 4.621 | 62.1% |

两组全部查询均有 6 次预测失败。共同查询来自 399 条轨迹；逐查询配对误差差值中位数为 +0.0018 px，95% 轨迹重采样区间 [−0.0027, +0.0067] px。没有明确的留出收益，因此[记录为未采用](../work/basketball/feature_refinement/normal_070_094/NOT_PROMOTED.json)，默认流程继续使用原始 LoMa 观测。

该结果只否定本次简单局部角点方案已取得明显收益，不能否定所有特征精化方法。精化改变了训练观测坐标，前后训练目标也改变，不能直接比较两组训练代价来判断相机准确性。

## 数值稳定性与复现

本轮所有拟合均采用 Huber 2 px、独立曝光位姿及正深度保护。另在不改变内参、观测、轨迹和验证规则的条件下，对三组迁移模型、两组主点消融及两组角点试验模型全部执行更大步长的继续求解，输出单独保存，未覆盖主要结果。详细结果见[数值检查记录](../work/basketball/numerical_checks/comparison.json)。

初始信赖域半径从 10 改为 10,000，上限从 10,000 改为 1,000,000，仍保留 400 次迭代上限及相同函数容差。这样检查“达到迭代上限后，以很小步长重启并立即报告收敛”是否掩盖了继续优化的空间。

| 模型 | 大步长检查状态 | 全部高置信查询 median / P90，检查前 → 后 |
|---|---|---:|
| 初始内参 | 收敛，结果稳定 | 1.646 / 5.805 → 1.646 / 5.805 |
| 70–94 候选 | 收敛，结果稳定 | 1.542 / 4.567 → 1.542 / 4.567 |
| 190–214 候选 | 再次达到迭代上限 | 1.539 / 4.565 → 1.524 / 4.568 |
| 仅修改 R cy | 继续 334 次迭代后收敛 | 1.537 / 4.707 → 1.532 / 4.707 |
| 完整候选但撤回 R cy | 收敛，结果稳定 | 1.661 / 5.663 → 1.661 / 5.663 |
| 原始 LoMa 训练点对照 | 收敛，结果稳定 | 1.644 / 5.455 → 1.644 / 5.455 |
| 角点精化训练点 | 收敛，结果稳定 | 1.640 / 5.381 → 1.640 / 5.381 |

70–94 迁移候选的单查询误差最大改变量仅 0.000203 px；它的主要结论不依赖小步长重启。190–214 候选则仍未充分收敛，单查询误差改变量的 P90 为 0.039 px、最大 1.140 px，因此保留数值不确定性，不因其某项分位数略低而优先选择。仅修改 R `cy` 的结论在继续收敛后保持一致。

七组检查的预测失败数均未变化；全部训练观测为正深度，最终正深度障碍项激活数及代价均为零。上述主表保留原始试验输出，本节明确列出后续数值检查，未悄悄替换模型或挑选较好的统计。

入口与命令见 [README](../README.md)。数值检查的原始执行脚本保存在 [runner.py](../work/basketball/numerical_checks/runner.py)，会拒绝覆盖已经存在的试验目录。LoMa commit、SegFormer revision、权重/模型/输入约定哈希、软件版本及代码快照保存在来源记录中。审计检查源图与 mask 身份、独立 frame、训练与留出隔离、固定内参、共同拓扑、正深度以及原始模型未被覆盖。`pytest -q tests` 的 **12 个针对性测试通过**，覆盖相关数学与隔离约定，不能替代场景精度验收。

## 对全场 3DGS 流程的影响

目前更合理的候选是数值稳定的 70–94 内参；它可以作为后续全场求解的起点，不能锁定为真值或直接写回 `.pro`。L/R 仍应分别共享可优化内参，每张曝光独立估计位姿。当前证据没有支持启用 M、加入导航姿态强约束或直接采用 LAS 坐标。

下一步应先补强训练轨迹的多视图一致性检查，并建立一组可复核的静态实体对应，重点覆盖 L/R 外圈及重复结构。随后扩展到全部 536 张已入选图像，检查全场连通、回环和共享内参 BA 的稳定性；几何满足要求后，再处理曝光/颜色及动态区域的一致性，完成 LichtFeld-Studio 的相机与视图导出。

本轮没有运行完整 536 张 SfM、LAS 配准或 LichtFeld-Studio 训练。已经得到可迁移的改善证据，同时保留了误差尾部、数值未充分收敛和无像素真值的限制，尚不宣称完成最终 3DGS 数据验收。
