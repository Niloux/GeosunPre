# 篮球场 SfM：弱约束与冲突训练轨迹清理

**标注语义修正（2026-09-23）**：用户说明旧人工标注仅为粗略分类，绝大多数像素坐标未精调；“动态”主要指难以确认的叶片/植被点。下文 114 条所谓“人工静态点”只是标为 `same_static` 的原始 LoMa 查询，数值保留作探索性对照，**不能判定精确位姿或轨迹清理是否真的变好/变差**。见[说明](../work/basketball/global_sfm/static_validation/annotation_semantics.json)。

上一轮 LFS 训练视图仍有明显地面细线模糊；近地面整体增权未形成清晰收益。本轮**只处理 SfM**：从已经用于 LFS 等权组的视觉模型出发，清理训练侧弱约束或相互冲突的三维轨迹，重新联合优化每张异步曝光位姿、三维点和 L/R 各自共享的 `OPENCV_FISHEYE` 内参。原始 JPEG、LoMa 二维坐标、LFS 配置与训练输出均未改动；导航 pose 数值和 LAS 不参加。

## 冻结输入与筛选

[协议](../work/basketball/global_sfm/sfm_track_cleanup/protocol.json)锁定源模型、留出划分、人工标注文件哈希和筛选阈值。筛选**不读取**任何人工点或留出查询误差。整条原始特征轨迹的留出隔离在筛选前后均检查。

- 同一三维点在同一图像关联多个特征时，删除整条有歧义的训练轨迹：261 点。
- 一条训练轨迹中任意两视线的最大夹角仍小于 2° 时，删除弱视差点：4,702 点。
- 其余轨迹删除当前鱼眼重投影误差超过 3 原图像素的观测；如果剩下少于 3 个观测，则删除该点：1,293 点。保留轨迹上单独删去 12,302 条观测。

点数 / 观测数从 **61,590 / 387,852** 变为 **55,334 / 345,543**。过滤后的 536 张图仍在一个连通分量中；单图至少 181 个观测、17 个 8×8 空间网格，全部观测正深度。[筛选审计](../work/basketball/global_sfm/sfm_track_cleanup/filter_audit.json)和[未优化的过滤模型](../work/basketball/global_sfm/sfm_track_cleanup/filtered_initial/sparse/0)均已保存。视差角度和重投影误差来自当前视觉模型，只是待验证的可靠性代理，不是静态实体真值。

## BA 与冻结核对

与旧模型同样使用原生鱼眼投影、2 px Huber、正深度保护、两位姿尺度规约和原有共享内参边界。新候选在 37 个有效步后收敛，用时约 193 秒，深度障碍没有激活，内参没有触边。相对旧模型，图像中心移动中位数约 0.00195 **视觉模型单位**、旋转中位数约 0.048°；不能把视觉单位解释为米。[BA 记录](../work/basketball/global_sfm/sfm_track_cleanup/candidate/ba.json)与[候选模型](../work/basketball/global_sfm/sfm_track_cleanup/candidate/sparse/0)保留完整结果。由于训练观测集合不同，优化代价不能直接横向比较。

所有误差为原始 3000×4000 图像像素。同一批冻结查询的结果如下；“≤2 px”以全部人工点为分母，无法预测的 6 条仍在分母中。

|核对集|等权原模型 median / P90|清理后 median / P90|其他|
|---|---:|---:|---|
|粗标 `same_static` 的原始 LoMa 查询 114 条|1.793 / 6.933|1.806 / 7.183|≤2 px：55.3% → 54.4%；108 条可配对查询的中位变化 −0.027 px，69 条改善|
|其中近场地面代理 30 条|1.547 / 3.025|1.534 / **3.272**|≤2 px 两组均为 70%；配对中位变化约 +0.001 px|
|直接闭合三图查询 10,855 条|1.921 / 6.847|1.911 / 6.830|不是人工静态真值|

数字取自[完整对照](../work/basketball/global_sfm/sfm_track_cleanup/comparison.json)，其中还有 L/R、图像中心与外圈分组。清理后的粗标查询 P90 上升，近场代理组没有明确配对收益；三图留出的收益只有约 0.01–0.02 px。由于粗标查询并非精确真值，这些结果只能说明**尚无足够证据晋升新候选**，不能否定更全面的前端优化。该候选[暂不晋升](../work/basketball/global_sfm/sfm_track_cleanup/NOT_PROMOTED.json)，原等权模型保持默认，LFS 没有重新训练或更换输入。

## 对后续 SfM 的指向

现有三图闭合规则可以留下重复建筑纹理、植被或遮挡轮廓；仅根据当前模型的残差、视差和同图重复关联删点，对高图像一致性的帮助有限。此前简单的原图角点亚像素精化也未取得明确留出收益。因此下一轮 SfM 应针对**原始对应是否属于同一静态实体、以及球场硬地和建筑等固定结构的约束覆盖**做诊断，再修改训练侧 LoMa 轨迹或相机参数模型。已有 114 条人工核对均未填场景类型，不能把“近场地面代理”直接当作球场线精度。更激进的筛选必须先检查早段 R 镜头等弱覆盖图像，不能重新采用曾误删球场铺装的宽泛植被掩码。

复算入口：

```bash
PYTHONPATH=src .venv/bin/python -m geosunpre sfm-track-cleanup --work work/basketball --stage audit
```
