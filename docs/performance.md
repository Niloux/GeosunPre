# 篮球场性能优化

后续内存与显存优化见 [资源记录](resources.md)。下文保留历史三轮对照，缓存大小对应当时实现。

## 计时与质量口径

目标是在当前 RTX 4090 / 8 个逻辑 CPU 的环境中，将全部 536 张 L/R 图像从原始输入处理为可独立校验的 COLMAP 交付包，耗时控制在 1,200 秒以内。
允许复用预训练模型权重；不得复用场景掩码、特征、匹配、标定或重建缓存。原图复制、掩码导出、最终几何评估和交付包校验计入完整运行。

参考运行是 `work/basketball_auto_20260928_01`，提交 `22a1a52`，实测 4,567 秒。
该记录早于工程重构；下文的全量对照已核对图像集合、前端结果和冻结留出观测。

## 实测结果

| 完整冷启动 | 耗时 | 达到 20 分钟 |
| --- | ---: | --- |
| 原参考运行 | 76 分 07 秒 | 否 |
| 原生 BA 与前端缓存 | 27 分 23.89 秒 | 否 |
| math attention 优化与 CPU 并行 | 23 分 09.07 秒 | 否 |
| 显式 FlashAttention 配置 | **19 分 51.30 秒** | **本次达到** |

第三轮相对原参考约 3.83 倍加速，距目标仅余 8.70 秒。这里是当前机器上的单次完整实测，
没有证明多次运行稳定低于 20 分钟。权重首次下载和编译安装不计入场景处理时间。

## 实现

- 掩码：按完整相机参数缓存两套虚拟视图采样、鱼眼射线映射和融合权重；相机设备遮挡和 FOV 栅格在一次运行内复用。保持单视图推理顺序和融合算术。
- 特征：一张原图只解码一次，复用 RGB 图像生成 detector / descriptor 的输入。保持 LoMa 固定版本的 PIL 缩放、float64 除以 255 后转 float32 的预处理；最多预取两张图像。特征 NPZ 改为无压缩存储，数组和身份计算不变，代价是更大的磁盘占用。
- 匹配：CPU 特征缓存增至 128 张，仅加载匹配所需数组；GPU 缓存按 512 MiB 上限淘汰。配对列表、顺序、模型、阈值不变。
- BA：`native/` 提供独立原生 `PositiveDepthCost`，保留原残差及解析 Jacobian；带约束求解使用 4 线程。正式默认要求原生扩展；Python 实现仅供显式诊断对照。
- 匹配算子：正式使用 FlashAttention；保留等价 math SDPA 优化用于诊断。单对 CUDA Graph 复用执行计划，只计算使用到的正向匹配输出。最多保留一个形状的图，其他形状走普通执行路径。
- CPU 并行：掩码后处理和写盘使用两个后台线程，最多四张概率图排队；检查预览、两视图几何验证和导出使用四个线程、最多八个任务排队。GPU 推理保持在主线程，几何验证保持每对显式随机种子和输入顺序。
- 评估：每个相机的固定 FOV 半径只计算一次，保留所有原有查询和失败预测分母。

匹配优化的参考实现来自固定版本 [PyTorch 2.8 math SDPA](https://github.com/pytorch/pytorch/blob/v2.8.0/aten/src/ATen/native/transformers/attention.cpp)。
诊断时可在单独配置中设置 `matcher_attention = "math"`；在此基础上，`GEOSUNPRE_MATCH_MATH=reference GEOSUNPRE_MATCH_GRAPH=0` 关闭 math 算子优化与图捕获。`GEOSUNPRE_DEPTH_BACKEND=python` 选择旧 BA；`auto` 显式允许缺失原生模块时后备。正式默认是 `native`，不自动降速。诊断应使用新工作目录。
普通多对 batch 的探测改变了匹配结果，未纳入实现。
`PipelineConfig.matcher_attention` 和唯一正式配置 `configs/basketball.toml` 均默认 `flash`。此前实验配置 `basketball_fast.toml` 已合并到正式配置。
FlashAttention 保留原模型、特征数量、配对和阈值，但浮点舍入不同，部分匹配会改变；该选择写入冻结配置和前端目录，匹配缓存身份单独区分。
此路径要求可用的 FlashAttention CUDA 内核，无法使用时直接报错。

原生扩展使用 Ceres 2.2.0 的最小 CostFunction 接口及构造/析构实现，不包含另一份求解器。源码附带原版权声明；pybind11 固定为与 pyceres 2.6 一致的 3.0.1。导入时拒绝不同 Ceres 版本。

## 安装和复现

```bash
uv sync --locked --extra loma --extra segmentation

HF_HUB_OFFLINE=1 \
  /usr/bin/time -v -o work/basketball_fast.time.txt \
  uv run --no-sync geosunpre run \
    --input input/篮球场 \
    --work work/basketball_fast_fresh \
    --config configs/basketball.toml \
    --model-cache /path/to/cached/huggingface/weights \
    --include-masks > work/basketball_fast.log 2>&1

uv run --no-sync geosunpre check --work work/basketball_fast_fresh
```

原生扩展已列为主工程必需依赖，构建需要 C++17 编译器和 Python 开发头文件；构建依赖由 uv 安装。缺失扩展时默认直接报错。
