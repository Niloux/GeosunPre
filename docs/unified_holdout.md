# 跨阶段观测留出

本协议仅适用于 `pipeline_mode = "validation"`；正式默认生产模式不划分留出集，见 [模式说明](production_pipeline.md)。

验证流程在局部标定和全局建图之前，冻结同一份观测留出集。局部标定复用全局特征的编号，全部几何阶段排除相同的留出观测。

## 顺序与规则

`prepare → masks → features → matches → holdout → calibration → sfm → finalize → export`

- 从符合长度和帧跨度要求的原始匹配轨迹中确定性抽取 20%，随机种子为 `314159`。轨迹的全部观测用于排除。
- 接触任一留出观测的匹配边，在两视图几何估计前被移除，包括未被原始成轨过程合并接受的冲突边。
- 高置信评估子集要求支持点与查询点间存在置信度至少 0.9 的直接闭合三图匹配。它在标定前冻结，不使用位姿或重投影误差选取。
- 局部标定片段由场景配置选择，图像、掩码、特征与匹配均复用全局准备产物。
- 局部划分是全局排除集合的投影。只有一至两个局部观测的轨迹也参与排除，但不生成评估查询；三个以上观测且帧跨度满足条件时，按帧顺序选首尾支持点，其余为查询。
- 失败预测保留在统计分母中。空查询显式记录为 `no_queries`。

## 身份文件

| 文件 | 内容 |
| --- | --- |
| `sfm/holdout_protocol.json` | 场景、前端、配对协议、缓存内容和划分哈希；最后写入，标志冻结完成 |
| `sfm/split.json` | 原始留出轨迹、支持点、查询点 |
| `sfm/triangle_validation_split.json` | 高置信留出子集 |
| `calibration/split.json` | 局部投影，包含不能评估的排除观测 |
| `calibration/run_contract.json` | 局部几何、配置、全局留出和实际使用的前端身份 |
| `calibration/calibration_identity.json` | 完成标定后保存全部阶段模型和求解报告哈希 |
| `sfm/geometry_protocol.json` | 全局几何绑定的留出协议和标定身份 |
| `sfm/final/protocol.json` | 最终 BA 的源模型、协议和求解设置 |

进入标定、全局几何、最终 BA 或正式导出时会重新核对依赖。缓存 token 相同但特征坐标重排、匹配内容修改、划分或标定模型改变，均拒绝继续。泄漏检查使用显式异常，在 `python -O` 下仍有效。

实验配置 `calibration_mode = "input"` 仍要求先冻结同一留出集，但不执行局部几何。
此时 `calibration/calibration_identity.json` 使用版本 2，保存输入相机参数、场景、配置和留出身份，
不伪造局部模型或四阶段 BA 产物；全局几何协议与导出来源明确记录 input 模式。
正式默认 local 的原有身份文件和续跑规则保持兼容。详见 [局部标定消融](calibration_ablation.md)。

## 评估用途

留出仍来自同批图像及原始匹配，每张图的其余观测参与了拟合。它用于比较各阶段对未参与拟合观测的预测情况，不是独立采集或真实三维点的验收，也不定义下游 3DGS 训练/测试划分。

完整流程导出的 `quality.json` 同时记录全部原始查询和高置信查询。交付后的 `check` 检查文件、身份和模型一致性，不需要接收方持有上游缓存，也不重新计算 SfM 质量指标。
