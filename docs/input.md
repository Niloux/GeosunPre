# 输入与相机坐标

```text
INPUT/
  场景.pro
  场景_CameraPos_C2E.txt
  场景_pos.txt
  场景_pos_ENH.txt
  Image/L/**/*.JPG
  Image/R/**/*.JPG
  ResultOut/场景.las
```

仅使用 `.pro` 中 L/R 相机及 CameraPos 有精确同名记录的 JPEG，M 不参与。图像名和各镜头帧号须唯一，Pose 绑定图像缺失时报错。尺寸须等于 `.pro`，EXIF orientation 须为 1。按 GPS 周、文件名时间、镜头和图像名排序；L/R 同帧号不表示同步。

文件名为 `GPS周-秒-毫秒_帧号-L或R.JPG`。CameraPos 每行 11 字段：文件名、设备编号、GPS 周、秒、XYZ、四元数四分量。仅使用位置，四元数不用于视觉初始化；不改写时间戳。

鱼眼参数为 `fx fy cx cy k1 k2 k3 k4`。初值：`fx=fy=focalLength/pixelSize`，`cx=width/2+principalX/pixelSize`，`cy=height/2+principalY/pixelSize`，`k4=p3`。主点偏移与 G203 参考流程采用相同的图像坐标方向；p3 含义尚未独立核对。旧版本对 principalY 使用减号，已有 scene.json 和特征缓存不能直接视为修正后的结果，须使用新工作目录。

左上像素中心为 `(0.5,0.5)`。`theta=atan2(sqrt(X²+Y²),Z)`，径向多项式为 `theta*(1+k1*theta²+k2*theta⁴+k3*theta⁶+k4*theta⁸)`。有效域为完整视场 160°，多项式须单调。L/R 内参各共享一组，每次曝光独立位姿。

两视图及 PnP 的 RANSAC 共识按原始鱼眼像素计算；透视归一化坐标仅供最小求解器产生候选。PnP 使用 AP3P 候选、6 px 内点门限及鱼眼位姿精调，不将中心与边缘观测混用同一透视坐标容差。

共享内参标定默认使用全部有效轨迹（`calibration_tracks=all`）；可选的 `stable` 仅使用轨迹长度至少 3、最大视差至少 1°、平均重投影误差不超过 2 px 的可靠点，并在标定后固定内参优化全部有效点。两档均在每次末尾标定前补全已验证匹配中未分配的轨迹，再检查同一组可靠轨迹：每幅已注册图至少 32 个观测和 8 个 8×8 覆盖格子，图像图保持连通，有注册图像的镜头分别至少覆盖三个 20° 角度带（每带 100 个观测）。覆盖不足且仍有补匹配轮数时，交给补匹配处理；进入可用子集收尾后，明确记录并排除可靠支撑不足的曝光，移除其观测后重新检查其余曝光。参考图像、图像图连通性或角度带不足仍明确报错。新增点参与随后的 BA，`all` 的双视图点不计入标定支撑。这些约束不替代独立检查点或厂商标定约定核对。

两份导航表行身份须一致，前五列为 GPS 周、秒、XYZ，时序递增。由成对位置拟合 ECEF→ENH 转换：尺度偏离 1 不超过 0.001、逐行残差不超过 2 cm。CameraPos 位置经该转换形成导航先验。

LAS 对齐后默认执行原图精修，以闭环一致的亚像素对应联合优化共享内参、位姿和可靠三视图点。未精修训练观测约束相对已验收重建投影的变化，与精修观测共用 2 px Huber 损失；LAS 法向约束相对原点的位移，保留导航约束。未精修像素不改写为预测值，误差验收仍使用实际像素和绝对 LAS 平面距离。

所有编号能被 5 整除的点固定留出，不参与相机优化；留出集包含成功精修及普通几何轨迹，按图像顺序确定性补充整条留出轨迹。每幅已注册图须有至少 16 个留出观测和 4 个 8×8 格子，训练也须有至少 16 个观测和 4 个格子；不足则不更新相机。至少 50 条成功精修的留出轨迹须同时改善误差中位数和 P90；全部留出轨迹及逐图误差、至少 8 个样本的 16×12 格子误差不得超过原值的 1.1 倍加 0.1 px。留出误差仍是固定相机重拟合点后的内部一致性，不代表独立三维精度。

相机候选须在强力删点前通过原几何质量及 LAS 残差检查；支撑不足或候选未通过时保留对齐模型，并记录原因。稀疏点清理另行验收照片保留率、LAS 支撑轨迹保留率和图像图连通性，不以删点代替相机精度改善。

相机优化的三视图要求不作为初始化点云的最低轨迹长度。精修清理允许双视图点，但仍须通过重投影、至少 1.5° 视差、固定相机下的深度不确定度及 LAS 距离检查；抽样 LAS 判远的点在删除前须按 50 万记录分块复核完整有效 LAS，距离门限不变，不要求点属于平面。SfM 最终标定后还会对已验证匹配分量中未分配的观测单独三角化，保留通过几何过滤的独立轨迹。

LAS 支持未压缩 1.2、点格式 0–3；多份使用 `--las` 选择。排除 withheld 和 class-7 噪声，RGB 支持 uint16 中的 8-bit/16-bit 范围，无 RGB 时灰色 127。

配准继承 `LAS XYZ ≈ ENH 减首个 ENH 位置` 假设，单位按米解释；拟合不能确认绝对 CRS 或独立地理精度。计算使用局部原点，输出恢复输入 LAS 坐标。

LAS 附色可能存在纹理错位，仅作为交付 PLY 的初始颜色。相机优化、原图精修、质量验收和点清理只使用 LAS 几何与有效点分类，照片对应来自原始图像，不以 LAS 附色作为相机标定或纹理对齐参照。
