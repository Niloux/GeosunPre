# 输入与相机坐标

调用方显式给出全部输入路径，程序不按目录结构或文件名配对自动查找：

| 参数 | 内容 |
| --- | --- |
| `--project FILE.pro` | PCC 解算项目（L/R 鱼眼标定） |
| `--images DIR` | 照片目录，可重复给出多个 |
| `--camera-pos FILE` | 逐张曝光位置（通常为 `场景_CameraPos_C2E.txt`） |
| `--pos FILE` | ECEF 导航表（通常为 `场景_pos.txt`） |
| `--pos-enh FILE` | ENH 导航表（通常为 `场景_pos_ENH.txt`） |
| `--las FILE` | 点云 |

新任务六项必须全部给出，缺少任意一项或文件不存在时报出对应参数和路径；只给 `--work` 续跑时沿用 `scene.json` 记录的路径。路径与源文件身份随工作目录冻结，改变须使用新工作目录。

仅使用 `.pro` 中 L/R 相机及 CameraPos 有精确同名记录的 JPEG，M 不参与；不在 CameraPos 中的 JPEG 直接忽略。镜头只由文件名后缀 `-L`/`-R` 决定，与所在目录无关，因此 `Image/L`、`Image/R` 分目录和全部平铺在同一目录均可：分目录时给 `--images Image/L --images Image/R`（或给其共同父目录），平铺时给该目录。每个 `--images` 目录若顶层直接含有所用 JPEG，按平铺目录只读顶层，其子目录（如 `enhanced/`、`Imageout/` 的派生副本）不读；顶层没有时递归读取整个目录树（如 `Image/L/0000/`）。同一图像名在所给目录中出现多次时报 `Ambiguous exposure` 并列出两个路径，CameraPos 中的 L/R 图像在所给目录都缺失时报错。建议传原图：enhanced 是逐图不同的非线性增强，原图保留真实线性响应，便于本程序统一完成多视角光度标定、暗角/白平衡对齐与 3DGS 外观建模；需要时可直接把 enhanced 目录作为 `--images`。交付图像名统一为 `镜头/文件名`（如 `L/xxx.JPG`），不保留调用方的目录层级；各镜头帧号须唯一。

所用照片尺寸须等于 `.pro`，EXIF orientation 须为 1。按 GPS 周、文件名时间、镜头和图像名排序；L/R 同帧号本身不表示同步：同时具有 L、R 的全部帧号的文件名时间相差不超过 2 ms 时按同步刚性 rig 处理（如室内、展厅）；超过 2 ms 且不超过 0.2 s 的异步错拍（如生产车间 R 先于 L 约 65 ms、古建筑约 56 ms），在 200 Hz 导航姿态通过视轴一致性自检时，按经 POS 运动补偿后的异步刚性 rig 处理。

文件名为 `GPS周-秒-毫秒_帧号-L或R.JPG`。CameraPos 每行 11 字段：文件名、设备编号、GPS 周、秒、XYZ、四元数四分量。仅使用位置，四元数不用于视觉初始化；不改写时间戳。

鱼眼参数为 `fx fy cx cy k1 k2 k3 k4`。初值：`fx=fy=focalLength/pixelSize`，`cx=width/2+principalX/pixelSize`，`cy=height/2+principalY/pixelSize`，`k4=p3`。主点偏移与 G203 参考流程采用相同的图像坐标方向；p3 含义尚未独立核对。

左上像素中心为 `(0.5,0.5)`。`theta=atan2(sqrt(X²+Y²),Z)`，径向多项式为 `theta*(1+k1*theta²+k2*theta⁴+k3*theta⁶+k4*theta⁸)`。有效域为完整视场 160°，多项式须单调。L/R 内参各共享一组，每次曝光有独立位姿；同步及通过导航姿态自检的异步数据在卷帘 BA 中均以全局 L→R 外参约束成对参考位姿。

两视图及 PnP 的 RANSAC 共识按原始鱼眼像素计算；透视归一化坐标仅供最小求解器产生候选。PnP 使用 AP3P 候选、6 px 内点门限及鱼眼位姿精调，不将中心与边缘观测混用同一透视坐标容差。

共享内参标定默认使用全部有效轨迹（`calibration_tracks=all`）；可选的 `stable` 仅使用轨迹长度至少 3、最大视差至少 1°、平均重投影误差不超过 2 px 的可靠点，并在标定后固定内参优化全部有效点。两档均在每次末尾标定前补全已验证匹配中未分配的轨迹，再检查同一组可靠轨迹：每幅已注册图至少 32 个观测和 8 个 8×8 覆盖格子，图像图保持连通，有注册图像的镜头分别至少覆盖三个 20° 角度带（每带 100 个观测）。覆盖不足且仍有补匹配轮数时，交给补匹配处理；进入可用子集收尾后，明确记录并排除可靠支撑不足的曝光，移除其观测后重新检查其余曝光。参考图像、图像图连通性或角度带不足仍明确报错。新增点参与随后的 BA，`all` 的双视图点不计入标定支撑。这些约束不替代独立检查点或厂商标定约定核对。

两份导航表行身份须一致，前五列为 GPS 周、秒、XYZ，时序递增。由成对位置拟合 ECEF→ENH 转换：尺度偏离 1 不超过 0.001、逐行残差不超过 2 cm。CameraPos 位置经该转换形成导航先验：SfM 转入导航坐标系后用于注册门限（0.25 m）和全部 BA（σ=3 cm），LAS 联合优化及卷帘 BA 使用同一先验。若 `_pos.txt` 另含后六列线速度与欧拉姿态角（Z-X-Y 顺序的俯仰、横滚、航向，约 200 Hz），则前移用于 SfM（手眼自标定、已知旋转两视图核验、2 点 PnP 及同镜头连续帧相对旋转先验）及卷帘阶段（先与视觉旋转作视轴一致性自检，单镜头中位残差不超过 2°），通过后提供各曝光时刻的载体姿态与世界系角速度。

相机按卷帘快门处理：每幅照片以读出中线时刻为参考位姿，沿读出轴坐标 c 的读出比例 `s = (c - N/2)/N`；读出轴为存储图像的行或列，按数据分别求解后择优，两镜头共用。读出转动按照片估计，读出时间按镜头共享并以符号表示读出先后；读出平移为读出时间乘以曝光时刻的相机系线速度：初值取 `_pos_ENH.txt` 在 CameraPos 时刻 ±20 ms 的插值差分速度（导航姿态自检通过时初始即叠加杆臂切向速度 `u_nav - ω_imu × r_cam`），准入通过后的终局精调（`polish`）再以 CameraPos 相对导航中心的杆臂 `r_cam` 叠加转动切向项 `u_nav - (ω/τ) × r_cam`（前端配对反向运动筛选仍用 `_pos.txt` ±50 ms 差分速度）。导航姿态自检通过时，同步/异步 rig 补偿与卷帘 BA 角速度正则亦使用该 200 Hz 姿态；物理读出检验（`ReadoutConsistency`）在 200 Hz 导航姿态通过视轴自检时优先使用曝光时刻 IMU 瞬时角速度，无 IMU 时回退同镜头相邻曝光视觉姿态差分；导航须覆盖每个曝光时刻前后，否则明确报错。配置 `"rolling_shutter": false` 时按全局快门处理。

LAS 对齐后默认执行卷帘快门校正和独立稀疏点清理。

相机候选须在强力删点前通过原几何质量及 LAS 残差检查；支撑不足或候选未通过时保留对齐模型，并记录原因。无论相机候选是否通过，稀疏点清理均独立执行，另行验收照片保留率、LAS 支撑轨迹保留率和图像图连通性，不以删点代替相机精度改善。

相机优化的三视图要求不作为初始化点云的最低轨迹长度。稀疏点清理允许双视图点，但仍须通过重投影、至少 1.5° 视差、固定相机下的深度不确定度及 LAS 距离检查；抽样 LAS 判远的点在删除前须按 50 万记录分块复核完整有效 LAS，距离门限不变，不要求点属于平面。SfM 最终标定后还会对已验证匹配分量中未分配的观测单独三角化，保留通过几何过滤的独立轨迹。

LAS 支持未压缩 1.2、点格式 0–3，由 `--las` 指定。排除 withheld 和 class-7 噪声，RGB 支持 uint16 中的 8-bit/16-bit 范围，无 RGB 时灰色 127。

配准继承 `LAS XYZ ≈ ENH 减首个 ENH 位置` 假设，单位按米解释；拟合不能确认绝对 CRS 或独立地理精度。LAS 头部范围（外扩 2 m）包含过半照片的 CameraPos ECEF 位置时，按 ECEF LAS 处理：读取时以导航的同一 ECEF→ENH 转换换到上述局部坐标，头部范围取转换后八个角点的包围盒，各阶段报告的 LAS 元数据记录 `frame: ecef_to_navigation_enh` 及 `frame_from_input` 变换；否则按局部 LAS 原样读取。计算使用局部原点，输出恢复局部 LAS 坐标（局部 LAS 即输入坐标）。

LAS 附色可能存在纹理错位，仅在未启用光度校准或多视角覆盖不足时作为交付 PLY 的初始颜色（默认按校准多视角去反光漫反射重着色）。相机优化、质量验收和点清理只使用 LAS 几何与有效点分类，照片对应来自原始图像，不以 LAS 附色作为相机标定或纹理对齐参照。
