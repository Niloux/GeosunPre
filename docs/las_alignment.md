# 视觉重建与 LAS 配准及联合优化

默认 `run` 在视觉建图后自动执行 `register`：全局配准、固定内参联合 BA、验收与 LAS 坐标交付。
`geosunpre align` 保留为独立命令，可从已有纯图像 COLMAP 交付生成全局配准候选与诊断报告。
配准不重新建图，联合阶段固定内参；不修改输入模型、导航文件或原始 LAS。

## 默认主流程与交付选择

新任务的 `registration_mode = "joint"` 默认开启，正式篮球场配置和 `./run.sh` 已采用这条路径。
输入需要唯一的 `CameraPos_C2E`、同名前缀的 `pos` / `pos_ENH`，以及未压缩的 LAS 1.2 点格式 0–3。
默认读取唯一的 `ResultOut/*.las`；有多份时设置 `registration_las` 为输入根目录内的相对路径或绝对路径。
`registration_pose_frame = "enh_first"` 明确记录下述 ENH 原点假设；时间戳与四元数不自动校正。

视觉 SfM 和局部/共享内参标定保持图像驱动，之后固定其内参。联合阶段优化每次曝光的位姿、
视觉三维点及视觉到 LAS 的全局 Sim3；输入位置为弱先验，LAS 为鲁棒点到面约束。
正式模式只执行 `pure_image_ba` 和 `pose_las` 两支，预算相同；独立 `joint-alignment` 继续保留三方案对照。
这版使用几何重投影一致性，不包含逐像素光度优化或联合内参释放。

交付首先要求全局配准达到冻结的操作门槛，所有几何选择都只用 LAS **fit** 区域：

| 验收项 | 默认门槛 |
| --- | --- |
| 稳定表面支持 | 至少 100 个 fit 点、5 个固定空间瓦片；支持比例至少 25% |
| 获支持 fit 点到面误差 | median ≤ 0.10 m，P90 ≤ 0.30 m |
| 瓦片误差 | 有至少 30 个获支持点的固定瓦片，P90 ≤ 0.50 m |
| 联合覆盖回归 | 相对全局配准，支持比例下降 ≤ 2 个百分点；共同支持保留至少 90% |
| 联合几何回归 | 共同支持 fit 点的整体、水平、竖直和固定瓦片，median 增加 ≤ 5 mm，P90 增加 ≤ 20 mm；分组至少 30 点 |
| 联合图像回归 | 相对相同预算的纯 BA，通过下文整体、L/R、径向、逐图和空间瓦片门槛，以及有限投影、正深度和更新幅度检查 |

门槛按固定点身份与空间划分计算。稳定支持沿用平面有效性与最近距离 ≤ 0.30 m 的对应规则，
点到面统计只覆盖获支持点；报告同时保留全部合格点的最近距离与支持比例，并限制共同支持损失。
获支持组内不按点到面误差再次裁剪。LAS 留出仅作描述性报告，
不用于选择交付、调权重或调阈值。这些门槛用于拦截明显退化，不证明相对历史候选的精度提高。

联合结果通过全部检查时采用 `pose_las`；联合候选失败或可靠约束不足时，回退到已验收的
`global_registration`。全局配准失败则停止，不交付未经配准的视觉模型；
原生后端、输入身份或产物完整性异常同样直接失败，不能以回退掩盖运行错误。
最终模型重新计算图像质量与覆盖，验证模式另行重算所选模型的留出预测。

```text
WORK/registration/
  inputs.json                # LAS/导航哈希、单位与原点假设、冻结门槛
  protocol.json              # 视觉源模型身份与实际求解配方
  visual_colmap/             # 内部视觉源，保留原生鱼眼及组合掩码
  global/                    # 全局配准与报告
  joint/                     # 纯 BA / pose + LAS 对照，或约束不足记录
  final/sparse/0/             # 唯一选中的 LAS 坐标模型
  final/result.json           # 实际采用分支及回退原因
  final/quality_summary.json  # 所选模型的图像诊断与配准验收
  final/inspection.html
WORK/colmap/                 # 唯一正式交付，默认复制原图，可包含掩码与 PLY
```

全局、联合和最终阶段先写完整目录与内容哈希，再原子发布。中断未提交阶段会归档后重算，
已提交结果复用前核对全量内容与上游身份；改动 LAS、pose、模型、掩码或提交元数据均拒绝继续。
最终来源记录写明 LAS 哈希、目标框架和实际采用分支。相机世界坐标与全部三维点已经位于 LAS XYZ，
下游 3DGS 不应再应用配准变换。LAS 坐标对齐不等于高斯训练后自动保持局部几何，仍需训练后检查。

纯图像研发消融可在新目录设置 `registration_mode = "visual"`。
配置版本 1–4 的历史目录保持 visual 语义，冻结字节不重写；执行源码身份检查仍然有效。

默认流程已在篮球场的 536 张图上完整冷启动、独立验包及缓存续跑。
联合分支通过图像门槛，但 4 个冻结 fit 瓦片发生局部退化，最终采用已验收的全局配准回退模型。
该结果与下文旧模型上的三方案探索分别记录，不把早期探索结论替代本轮交付选择。
详见 [联合流程实跑](production_pipeline.md#默认联合流程完整运行验证2026-09-30) 和
[可追溯摘要](benchmarks/basketball_joint_pipeline_20260930.json)。

## 运行

```bash
uv run --no-sync geosunpre align \
  --colmap work/basketball_industrial_01/colmap \
  --las input/篮球场/ResultOut/篮球场.las \
  --input input/篮球场 \
  --output work/basketball_las_alignment_01
```

输出目录须为空或不存在。默认最多采样 150 万个 LAS 记录，空间查询使用 4 个 CPU worker。
只需要现有 NumPy、SciPy 和 PyCOLMAP；不依赖 Open3D，不使用 GPU。
原型读取未压缩 LAS 1.2 的点格式 0–3，拒绝其他版本、LAZ 和截断文件。
坐标按标准的整数值、scale 和 offset 解码，见 [ASPRS LAS 1.2 规范镜像](https://liblas.org/_static/files/specifications/asprs_las_format_v12.pdf)。

`run` 会冻结整个包的执行源码；新增命令与模块改变执行身份，旧任务不能直接按新源码续跑。
已有视觉交付可直接传给 `align`，无需改写旧任务协议或重跑 SfM。

也可提供显式初值，替代 `--input`：

```bash
uv run --no-sync geosunpre align \
  --colmap /path/to/visual/colmap --las /path/to/cloud.las \
  --initial-transform /path/to/initial.json --output /path/to/new/alignment
```

JSON 的 `matrix` 为 4×4 矩阵，方向为 `X_las = s R X_visual + t`。
必须包含正的统一尺度和正常旋转；不接受镜像、非均匀缩放或非有限参数。

## 初始化的坐标假设

`--input` 使用同名 `CameraPos_C2E`、`pos.txt` 和 `pos_ENH.txt`。
先检验两份导航的行坐标能否通过近单位尺度的相似变换转换，再把 ENH 第一行位置作为局部原点。
按图像名称对应视觉相机中心与 CameraPos 位置，使用固定随机种子的 RANSAC 求初值。

这条路径明确提出“LAS 约等于 ENH 减去初始导航位置”的**候选假设**。
厂家坐标约定、LAS 原点及米制单位均未获得独立确认；几何细化和分区诊断用于检验它。
导航的按行坐标关系只用于拟合坐标转换，不表示时间同步。原始时间差全部记录，
不修改时间戳，不按行把相机曝光与导航对应，也不使用未经核实的四元数。
轨迹近似共线或导航坐标转换不成立时，要求显式初值。

## 配准与留出

1. 以固定种子在 LAS 记录顺序中分层采样，每个分层随机选择一个记录。
   分块读取，排除 withheld 和 class-7 noise；不使用颜色或配准残差决定采样。
2. 从视觉模型选择存储重投影误差 ≤ 2 px、轨迹长度 ≥ 4 的点。
   初值坐标超出 LAS 头部包围盒及 0.8 m 扩展范围的点不参与表面优化，数量单独记录。
   正式候选 COLMAP 保留全部源模型点和观测轨迹。
3. 在初值坐标中冻结 4 m 三维空间瓦片，随机留出 20% 的瓦片。
   留出比例按瓦片计算，点数比例可能不同。留出点不传入表面优化器。
4. 在 0.4 / 0.2 / 0.1 m 体素尺度估计局部表面，通过邻域协方差排除非平面和线状支持。
   用鲁棒点到面误差、每瓦片相同总权重细化 7 自由度相似变换，拒绝没有充分数值约束的更新。
   普通刚体 ICP 的尺度固定；本原型每次更新都同时优化正的统一尺度。
5. 在同一份最终尺度 LAS 表面上比较初值与细化结果，分别报告 fit / holdout。
   用初值与细化都获得支持的留出点做共同支持比较，按空间瓦片进行 500 次 bootstrap。

留出仅隔离 LAS 表面细化。pose 初始化使用全部对应相机，并不是完整的独立采集精度验证。
不依据留出结果选择初值、调参或自动替换原模型。水平/竖直表面按候选 LAS 的 Z 轴定义。
总体点到面 median 可能由大量水平表面主导，需要结合方向、覆盖和分区统计解释。

## 产物与验收边界

| 产物 | 内容 |
| --- | --- |
| `inspection.html` | 离线点云查看器、初值/细化切换、支持比例、方向统计和 L/R 原生鱼眼投影对照 |
| `report.json` | 输入与实现哈希、坐标假设、协议、优化过程、拟合/留出统计和诊断限制 |
| `transform.json` | 初值、细化后的视觉到 LAS 变换和尺度 |
| `regions.csv` | 全部空间瓦片的支持比例及初值/细化误差 |
| `registration_points.npz` | 视觉点 ID、冻结瓦片与划分、坐标、距离和稳定表面支持标记 |
| `las_sample.ply` / `visual_initial.ply` | 同一候选坐标中的 LAS 表面采样与初值视觉点 |
| `aligned_colmap/` | 同一个变换作用于相机和全部三维点后的候选 COLMAP，原图使用链接 |
| `result.json` | 本次完成状态、主要结果与源模型未改变记录 |

候选模型回读后检查所有图像、二维观测和三维轨迹身份，并抽样验证原生鱼眼重投影不变。
`geosunpre check --output .../aligned_colmap` 可以独立检查该候选包的内容完整性。
图像链接仍依赖源视觉交付目录；它不是复制原图的可搬移发布包。

状态固定为 `candidate_requires_review`，绝对精度未验收。
点到面指标只统计获得稳定表面支持的点，报告同时列出支持比例和全部合格点的最近点距离。
未获支持点、不同采集范围、非平面物体和错误视觉点均可能影响最近距离，
不能把该距离直接归因于 LAS 漂移。一个全局变换也不能消除局部形变或扫描运动误差。

## 篮球场首轮诊断

2026-09-30 复用 `basketball_industrial_01/colmap` 的 536 图、75,749 点模型，
不重跑视觉重建。LAS 原有 56,941,990 点，实际采样 1,498,474 点；
42,289 个视觉点符合优化范围，34,902 个用于拟合，7,387 个为空间留出。

| 留出指标 | pose 初值 | 表面细化 |
| --- | ---: | ---: |
| 稳定表面支持比例 | 48.00% | 48.14% |
| 共同支持点到面 median | 8.06 mm | 5.91 mm |
| 共同支持点到面 P90 | 44.76 mm | 44.03 mm |
| 全部合格留出点最近距离 median | 62.72 mm | 63.11 mm |
| 全部合格留出点最近距离 P90 | 652.32 mm | 654.89 mm |

共同支持 median 改变量的空间 bootstrap 95% 区间为 `[-4.21, +0.60] mm`，包含零，
当前未检出明确细化收益。细化后水平表面的留出 median / P90 为 `4.96 / 16.14 mm`；
竖直表面为 `76.81 / 226.27 mm`。这些条件统计不证明整场配准完成，也不代表绝对精度。

全局配准初值具备继续检查的条件。下一步应针对竖直固定结构和低支持区域核对对应关系，
再判断是否存在局部几何问题；本轮结果不支持直接进行非刚性修正或把 LAS 当作精确几何真值。
可追溯摘要见 [篮球场 LAS 配准记录](benchmarks/basketball_las_alignment_20260930.json)。

## 进一步检查结构与低支持区域

```bash
uv run --no-sync geosunpre inspect-alignment \
  --alignment work/basketball_las_alignment_01 \
  --output work/basketball_las_structure_01
```

该命令冻结已有变换，校验源模型、LAS、原配准报告与变换身份，
重新采样 LAS 并精确重现原有空间划分、支持标记和逐点残差。它不优化或替换模型。
已有配准目录保持原样，新目录保存 `inspection.html`、`structure_report.json`、
`structure_points.npz`、`support_points.csv`、`repeat_patches.csv` 及 `gallery/` 原图对照。

支持原因按距离、邻域采样、线状程度、平面程度、厚度顺序归类，主要原因互斥；
完整 JSON 同时保留各拒绝条件的重叠计数。每个视觉点另列轨迹长度、存储重投影误差和
全部观测之间的最大三角化角。角度描述观测几何，不是经过标定的深度精度估计。

代表区域按每组空间瓦片中的点数选择，扫描时段差异另选偏移最大的三个局部区域。
每个区域分别挑选 L/R 相机中该组观测最多的一张图，不要求同步曝光。
青色标点来自源 COLMAP 的真实二维观测；黄色为冻结变换下局部 LAS 投影，
没有完整遮挡判定。局部裁切保留原图细节，帮助区分告示牌、字牌、树冠与建筑。

LAS 重复扫描诊断在视觉点附近的 LAS 表面中心中，每个 0.5 m 空间格选一个候选中心，
最多检查 4,000 块，查询 0.45 m 球形邻域。局部 GPS time 间隔大于 3 s 时分为不同扫描时段，
选最早/最晚各至少 10 个样本、相隔至少 10 s 的两段。
单段须满足平面与面内二维支持条件、法向噪声 ≤ 3 cm，两段法向夹角 ≤ 15°。
两段在平面的切向坐标中双向寻找距离 ≤ 8 cm 的近邻，至少需 10 对且每段至少 10 个不同点。
报告法向差中位数、离散程度和样本数；这些成对样本并非统计独立观测。

薄板和构件的不同侧面可能通过上述平面条件，因此额外报告观察侧代理：
当 LAS 是 GPS week time 且图像名称提供同一 GPS 周的曝光时间时，
使用最接近的视觉相机中心判断其位于局部平面的哪一侧。
时差须 ≤ 0.6 s，相机到平面距离须 > 1 m；否则标为不确定。
相机中心不等于雷达扫描原点，外参及时间同步尚未核实。
代理能提示相反侧面歧义，同侧也不证明来自同一物体表面；其他时间格式不会被猜测转换。

### 篮球场结构诊断结果

2026-09-30 对同一份 42,289 点候选进行诊断，原有支持和残差逐点重现。

| 主要支持或拒绝原因 | 全部点 | 留出点 | 最大三角化角 median |
| --- | ---: | ---: | ---: |
| 获得平面支持 | 21,488 | 3,556 | 45.06° |
| 30 cm 内没有 LAS | 6,547 | 1,333 | 4.46° |
| 邻域采样不足 | 1,818 | 323 | 10.45° |
| 邻域近似线状 | 24 | 1 | 15.17° |
| 邻域不满足平面条件 | 12,412 | 2,174 | 18.20° |
| 厚度超限且未被更早条件归类 | 0 | 0 | — |

部分条件会同时失败，最后一行的零不表示不存在厚邻域；重叠厚度拒绝计数为 5,521。
低支持不能统一解释成错位：代表非平面区域的原图标点落在树冠，
超过 2 m 的距离区域包括远处建筑立面。无近距 LAS 支持组的三角化角较小，
提示视觉深度约束、两套数据的覆盖范围及遮挡也应一起检查，不能据此判定是哪套数据出错。

两个高误差竖直代表区域是近处告示牌和“9B”立体字。
报告展示的是**超过 5 cm 的问题点子集**，分别有 56 / 51 点，
条件点到面 median 为 59.4 / 109.0 mm，不能用来代表整个物体的配准误差。
同一“9B”空间瓦片也包含 11 个误差 ≤ 2 cm 的竖直支持点，
说明局部最近面对应关系和物体曲面/厚度都需要核对。

扫描时段检查了 3,463 块候选邻域，768 块通过几何比较条件：水平 742、竖直 25、倾斜 1。
最大的法向中位数差为 96.8 mm，位于篮球架构件；其观察侧代理为相反侧。
其他较大差异多为接近平面的观察侧不确定情况。
观察侧代理为同侧的 19 块竖直局部平面，法向差 median / P90 / max 为
`1.20 / 3.81 / 5.32 mm`；730 块水平局部平面为 `0.17 / 0.63 / 6.10 mm`。
这些有限条件统计不验证整份 LAS，也不排除其他区域的局部误差。
当前没有足够证据根据“最大 9.7 cm”就进行 LAS 轨迹或局部形变修正。

后续配准优先改进表面对应：结合原图排除植被及薄板/曲面歧义，
引入视觉深度几何条件与法向一致性，再对水平、竖直结构分组控制权重。
本报告已经检查了旧留出区域；据此调整配方属于探索，后续验收需要重新预留未参与设计的结构或独立数据。
追溯记录见 [篮球场结构诊断](benchmarks/basketball_las_structure_20260930.json)。

## 基于可靠结构继续细化

```bash
uv run --no-sync geosunpre refine-alignment \
  --alignment work/basketball_las_alignment_01 \
  --output work/basketball_las_refinement_01
```

新目录以参考候选的最终变换为初值，校验原模型、LAS、参考报告与变换哈希，
重现原始采样、点选择和空间划分。分区仍使用首轮坐标，避免移动初值后改变 fit / holdout。
优化器只接收 fit 点，参考候选及源模型保持原样，产物仍为待审查候选。

LAS 在 0.1 / 0.2 m 两个尺度都须呈现兼容平面，法向噪声和尺度间面差均不超过 2.5 cm。
视觉点的精度代理来自原生相机投影 Jacobian，假设相机、内参固定及至少 1 px 的像素噪声。
它只用于相对筛选与权重，不是完整 BA 协方差，不能把该数值当作实际深度精度。
最大条件标准差代理须 ≤ 30 cm；视觉邻域法向可靠时，要求与 LAS 法向差 ≤ 25°。
视觉稀疏点不能可靠估计局部法向时，仅允许最大标准差代理 ≤ 10 cm 的点参与。
法向缺失与法向冲突分别处理；平行表面存在竞争对应时拒绝使用该点。

水平、竖直、倾斜结构分别按空间瓦片均衡，并用相对精度和 LAS 平面噪声衰减权重，
防止地面点数量主导更新。除数值 Jacobian 秩检查外，完整 7 自由度细化还要求
至少 100 个竖直对应、5 个瓦片及足够的竖直法向方向分布；覆盖条件每次更新都需保持。
竖直覆盖不足但水平覆盖足够时，只释放小角度 X/Y 倾斜和局部枢轴 Z 位移，
继承参考候选的统一尺度及其他配准自由度。两者都不足则保留参考变换。
所有更新还受总旋转、尺度与枢轴位移范围约束。

报告沿用首轮评价表面，不使用更严格的新优化筛选来美化评价范围。
`inspection.html` 增加固定方向分组的共同支持前后对照；
`structural_fit_points.npz` 保存 fit 点的精度代理、法向可用性、最终对应和歧义标记。
该命令并未使用 pose 残差或修改相机位姿、内参；仍只优化整场相似变换。

### 篮球场结构细化结果

最终探索候选为 `work/basketball_las_refinement_20260930_04`。
拟合点仍为 34,902 个，初始可靠竖直对应 455 个、覆盖 92 个瓦片，
本轮允许完整 7 自由度细化，所有已求解更新均达到数值秩 7。

| 冻结方向分组、两版共同支持的留出点 | 点数 | 参考 median | 细化 median | 参考 P90 | 细化 P90 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 水平 | 3,060 | 4.94 mm | 4.95 mm | 15.98 mm | 16.62 mm |
| 竖直 | 387 | 76.81 mm | 71.60 mm | 217.66 mm | 228.54 mm |

竖直中位数下降约 5.2 mm，但 P90 增加约 10.9 mm；其 median 改变量区间也包含零。

这些区域已经用于分析与调整方案，以上只能作为探索性对照，不能称为独立精度验证。

早期仅接受视觉局部法向的方案几乎排除了竖直结构：7 个竖直对应只覆盖 1 个瓦片。
强行求 7 自由度虽达到数值满秩，却明显恶化竖直误差；加入覆盖保护后退化为地面倾斜/高度细化，

最终方案对法向不可用但条件精度较好的稀疏点开放对应，恢复了竖直覆盖，仍未宣称配准精度提升。

实现通过 114 项测试；真实候选的 536 张图、75,749 点已独立验包，

离线查看器数据、绘制及交互已通过 Node VM 检查，未做真实浏览器视觉验收。
这证明候选构建与全局变换的投影不变性，不证明下游 3DGS 质量。

## 后续图像主导的联合优化设计

以下设计的固定内参阶段已由 `joint-alignment` 实现并完成篮球场对照；内参释放阶段尚未执行。
其目标是在保持图像一致性的前提下，
利用输入 pose 和可靠 LAS 几何约束相机位姿、视觉三维点与两套坐标的关系。
整场相似变换只能调整整体位置、方向和尺度；联合 BA 才能调整局部轨迹与三维点几何。

以纯图像模型作为初值，变量为每次独立曝光的位姿 `T_i`、视觉点 `X_j`、
视觉到 LAS 的相似变换 `S` 和 L/R 各自共享的内参 `theta`。三类残差分别为：

```text
图像：project(theta, T_i, X_j) - observed_pixel_ij
pose：S(camera_center(T_i)) - input_camera_center_i
LAS：normal_q dot (S(X_j) - surface_center_q)
```

先固定内参和 LAS，联合优化位姿、三维点与全局变换。
图像重投影为主约束；pose 位置与 LAS 点到面为带不确定度、鲁棒损失的软约束。
外循环更新可信表面对应，内循环固定对应求解，并限制相对纯图像初值的更新幅度。
需要明确固定视觉坐标的规范自由度，否则 `T_i / X_j / S` 之间存在相互抵消的全局相似变换。

输入 pose 先使用按图像名对应的相机中心。姿态四元数约定、外参和曝光同步核实后才加入姿态先验；
导航文件按行坐标可转换不代表时间同步，也不修正现有约 355–357 ms 的原始时差。
L/R 仍是独立曝光，不根据同帧号强行绑定位姿。
pose 与 LAS 可能共享导航误差，不能将它们直接当作两份独立高精度真值。

LAS 对应继续筛选可靠固定结构、平面多尺度一致性、可见性与薄板侧面歧义。
植被、动态物体、弱采样及冲突对应降低权重或退出约束，不把整份 LAS 逐点当作真值。
首版固定 LAS 点坐标。若后续证据支持修正 LAS，需使用具有物理意义且有先验的轨迹或外参参数；
自由移动每个 LAS 点会让约束退化，目前也没有支持扫描运动修正的完整原始数据。

固定内参的版本稳定后，再分阶段、小范围释放 L/R 共享焦距和低阶畸变，
必要时再检查高阶畸变及主点。内参范围围绕当前视觉标定，继续检查正深度与鱼眼投影单调性。
不能通过畸变参数吸收 LAS 的局部误差。已有有界 BA 和深度保护可复用；
当前安装的 PyCOLMAP 4.2.0 提供位置先验及其协方差接口，LAS 与全局变换的联合残差需要扩展。
[COLMAP 的位置先验文档](https://colmap.github.io/faq.html#reconstruction-with-pose-priors-gps)说明了先验协方差的用途，
[主点优化文档](https://colmap.github.io/faq.html#principal-point-refinement)也说明主点估计可能不适定。

“图像优先”通过独立接受条件落实：除了混合目标下降，还要检查整体及逐相机/区域的图像误差尾部，
更新不得超过预先约定的视觉退化容限；冲突时回退或降低 pose/LAS 权重。
像素与米的残差先按各自噪声尺度归一化，并控制空间和观测数量的权重，不能只把一个系数设大。

有来源记录的纯图像、加 pose、加 pose+LAS、再释放内参四组对照应分别保存。
正式几何验证需要在两组对照拟合及标定前冻结未参与设计的数据，而不是继续沿用已检查的旧留出区域。
特征重投影更好只说明稀疏图像约束，3DGS 质量还需要后续授权的相同训练配置与独立视角渲染对照。
本轮复用现有图像模型做联合 BA，未重跑特征、匹配、建图或 3DGS 训练。

## 固定内参联合 BA 实跑

修改原生扩展后，先按 [原生模块说明](../native/README.md) 重建项目环境中的扩展，
再运行独立命令：

```bash
uv run --no-sync geosunpre joint-alignment \
  --alignment work/basketball_las_alignment_01 \
  --input input/篮球场 \
  --output work/basketball_joint_alignment_01
```

运行从参考候选追溯并独立验包源纯图像模型，核对 LAS、导航、原报告和变换，
重现原有点选择、空间划分及逐点 LAS 残差。随后在相同初值上分别执行三组固定内参 BA：
`pure_image_ba`、`pose_only`、`pose_las`。默认每组最多两轮，每轮最多 20 次 Ceres 迭代。
图像使用全部 482,527 个既有观测；LAS 对应只使用原有 34,902 个 fit 点。

### 优化变量和接受条件

位姿与视觉三维点保留在视觉坐标中，使用 COLMAP 的 `TWO_CAMS_FROM_WORLD` 消除视觉规范自由度。
额外的全局 Sim3 独立优化旋转、平移和正的统一尺度，因此视觉坐标锚点不固定 LAS 中的绝对位置。
全局旋转为单位四元数，尺度参数为 `log_scale`。所有图像观测、三维轨迹及 L/R 共享内参保持身份一致。

输入相机中心使用 0.5 m 的保守噪声代理，LAS 点到面使用 0.05 m；均为可配置代理，未经传感器标定。
默认 pose / LAS 的归一化目标预算为 `0.001 / 0.005`，分别乘图像观测数，并按位置观测数及平面分组权重分摊。
鲁棒阈值为 2 倍各自噪声尺度，权重不会改变物理鲁棒阈值；图像仍使用 2 px Huber。
坐标转换、原始导航时间差和未使用姿态四元数的事实全部记录。

每轮更新必须满足混合目标下降、正深度保护、固定内参及身份检查和图像回归门槛。
超限时在旋转流形上回退位姿和全局旋转，对相机光心、三维点及尺度对数插值。
仍无合法更新则保留该轮之前的状态，并保存被拒绝的原始提议，供审查。
最终还需和相同求解预算的纯图像 BA 比较，才能标为 `candidate_image_gate_passed`。

图像分组和空间瓦片在求解前冻结，不按更新后的误差挑选观测。
全部观测须有有限投影和正深度；整体、L/R、中心/中部/边缘、单图和空间瓦片都检查 median / P90 / P99。
分组统计门槛至少要求 30 个观测，小组仍进入整体有限性检查，不把失败观测从分母剔除。

| 分组 | 允许 median 增加 | 允许 P90 增加 | 允许 P99 增加 |
| --- | ---: | ---: | ---: |
| 整体 | 0.02 px | 0.05 px | 0.10 px |
| 相机 / 相机径向分组 | 0.03 px | 0.08 px | 0.15 px |
| 单图 | 0.05 px | 0.10 px | 0.20 px |
| 固定空间瓦片 | 0.10 px | 0.20 px | 0.30 px |

这些是首版探索的回归容限，不是标定不确定度，也不表示逐像素光度一致性。
几何限制同时检查局部相机位移 ≤ 15 cm、局部旋转 ≤ 0.5°、三维点局部位移 ≤ 50 cm，
以及全局旋转 ≤ 1°、尺度对数变化 ≤ 0.005、相机轨迹枢轴位移 ≤ 15 cm。
三维点还设置每坐标 ±20 cm 的边界，防止弱三角化点远移来抵消相机调整。

### 篮球场结果

交付候选为 `work/basketball_joint_alignment_20260930_02/stages/pose_las/colmap`，
离线报告为同一运行目录下的 `inspection.html`。
三组均保留 536 图、75,749 点、全部观测轨迹和原有组合掩码字节，
原图使用链接；源纯图像交付及参考配准保持原样。

| 图像指标，全部 482,527 个拟合观测 | 固定内参纯 BA | 图像 + pose + LAS |
| --- | ---: | ---: |
| median | 1.071640 px | 1.071555 px |
| P90 | 2.348020 px | 2.348172 px |
| P99 | 3.732152 px | 3.732363 px |

联合结果的整体 P90 增加约 `0.00015 px`；单图最大 median / P90 / P99 增加约
`0.00662 / 0.02453 / 0.05524 px`，全部图像及分区回归检查通过。
局部相机最大位移约 `0.091 mm`，最大旋转约 `0.000469°`；
三维点最大局部位移约 `22.5 cm`。全局配准旋转约 `0.0485°`，相机轨迹枢轴位移约 `3.21 cm`。
所以本轮主要改变了配准及部分三维点，不能说相机轨迹获得了明显修正。

LAS 旧留出支持比例为 `48.14% → 48.19%`。
两版共同支持的 3,514 个留出点，点到面 median 为 `5.93 → 6.07 mm`，
P90 为 `45.48 → 42.84 mm`；median 改变量的空间 bootstrap 95% 描述区间为 `[-1.23, +2.58] mm`。
共同支持的 397 个竖直点，median 为 `74.07 → 72.02 mm`，P90 为 `213.40 → 225.97 mm`，
median 改变量区间也包含零。整体几何收益没有得到明确证明。

只加入 pose 的分支更接近输入位置：位置差 median 为 `36.53 → 26.49 mm`，
但旧 LAS 留出支持比例为 `47.99%`，不代表配准或绝对位置更准确。
联合分支的位置差 median 为 `36.72 mm`，允许图像和 LAS 与输入 pose 的偏好存在冲突。

原生解析 Jacobian、实际 Ceres 联合求解、单图退化拦截、旋转回退、拒绝提议后的状态保留、
组合掩码保留及旧流程共计 122 项测试通过。候选包另外进行独立验包，
全部 482,527 个观测从导出模型重新投影，与保存误差一致；原生全局变换投影检查也通过。
离线报告的逐图筛选、方案/统计量切换及本地链接通过 Node VM 校验；未做真实浏览器视觉验收。
数值结果属于已拟合图像观测及已检查的旧 LAS 区域上的探索，不是独立几何或 3DGS 质量验收。

每组 `stages/<name>/` 保存 `round_*.json`、`diagnostic.json`、视觉模型、LAS 坐标模型、
逐观测误差 NPZ、原有 LAS 点划分与候选 COLMAP。顶层 `protocol.json` 冻结配方、门槛和实现身份，
`report.json` 与 `inspection.html` 汇总对照。新候选含局部几何变化，不能只用一个 `transform.json`
还原其全部相机和三维点；应使用已导出的完整模型。

目前支持继续采用图像主导的联合优化机制，但没有证据支持直接宣称配准精度提升或立即释放内参。
下一步应核对高误差竖直结构对应和弱深度点，并预留未参与设计的数据用于验收。
