## 运行与证据范围

配置协议为 8，依赖版本未升级。复用了 536 幅特征、语义掩码和 5,941 对原始匹配，新匹配 4,484 对；没有复用局部/全局数值模型。阶段记录约 1,061.17 秒，不是从头提取、复制原图的完整进程性能对照；候选数增加也不能被解释为成本下降。

```bash
./run.sh --input input/篮球场 --work work/generalization_20261009 \
  --stage prepare --image-mode link
# 验证前复制未变化的 features、matches、sfm/masks 和 sfm/mask_review 缓存，保留文件元数据
./run.sh --work work/generalization_20261009
```

编译、Shell、配置/链接、候选图确定性、合成薄弱图补边和冻结区域重放检查通过。联合求解被跳过，另核对了全部 457,477 条联合观测投影及区域重放；本轮没有运行联合 Ceres 求解。提交前整理只清理重复计算、未用变量和旧描述，定向核对自动选择、匹配图及已有成果。

这是组合改造的单场景流程回归，未隔离单项算法收益，也未验证道路/建筑/室内、独立几何或 3DGS 渲染质量。噪声代理范围内跳过联合 BA 的结果不证明它在其他场景无用。
