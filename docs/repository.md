# 仓库整理与正式默认

## 本次采用的版本

2026-09-29，采用已完成第三轮篮球场全量验证的优化方案作为正式默认。
正式命令仍为 `run / export / check`，正式篮球场配置统一为 `configs/basketball.toml`。

| 内容 | 当前状态 |
| --- | --- |
| FlashAttention + 单对 CUDA Graph | 新运行默认；后端写入冻结配置与匹配身份 |
| C++ 深度约束 + 4 线程 BA | 主工程必需依赖，默认要求可用 |
| 特征预取、CPU/GPU 特征缓存 | 默认启用，有容量上限 |
| 掩码映射缓存、CPU 后处理、几何验证和导出并行 | 默认启用，按原输入顺序收集结果 |
| 每相机 FOV 半径复用 | 默认启用，保留原评估分母 |
| math attention / Python 深度约束 | 保留用于诊断及原配置续跑，不作为新运行默认 |
| 多对 batch 等未采用实验 | 仅保存在本地 `work/`，不进入正式模块 |

## 仓库内容

| 路径 | 用途与管理方式 |
| --- | --- |
| `src/geosunpre/` | 正式 Python 实现 |
| `native/` | 原生扩展源码、构建说明、Ceres 接口及许可证 |
| `configs/` | 正式场景配置，合并重复的 basketball fast 配置 |
| `tests/` | 数值正确性、缓存隔离、配置迁移、并行任务和交付契约检查 |
| `docs/` | 使用说明、契约、性能记录和本整理说明 |
| `docs/benchmarks/` | 小型验证摘要、运行身份和原记录哈希，可随仓库保存 |
| `input/` | 原始数据，保留原位置，Git 忽略 |
| `work/` | 原有重建、实验脚本、完整日志及产物，保留原位置，Git 忽略 |
| `.cache/` | 模型权重，保留，Git 忽略 |
| `.codegraph/` | 本机代码索引，保留，Git 忽略 |
| `.venv/`、`build/`、`dist/`、`*.egg-info`、`*.so` | 本机环境和构建产物，Git 忽略 |

工作目录内存在绝对路径和冻结身份，因此本次没有移动、重命名或删除运行目录。
该整理不包含数据清盘；磁盘中仍保留各轮实验的完整证据。

## 配置与恢复

- 新配置版本为 2，默认 `matcher_attention = "flash"`。
- 版本 1 未包含后端字段的冻结配置按 `math` 读取；显式指定的 `flash` 继续生效。
- 保存相同配置不改写旧文件，避免连带改变下游身份。
- 旧目录续跑省略 `--config`；采用新默认时使用新 `--work`。
- Flash 与 math 不共享匹配缓存；原始特征的计算与身份保持一致。
- 原生模块缺失时默认报错；诊断后端的显式选项见 [性能记录](performance.md)。

## 验证范围

正式默认对应一次 19 分 51.30 秒的完整冷启动；全部 536 张注册、交付校验和共同留出检查通过。
距离 20 分钟仅余 8.70 秒，尚无稳定耗时上限或下游渲染质量结论。
本次整理验证默认值、旧配置恢复、包构建和安装，不重复执行完整 GPU 流程。

整理后验证结果：48 项测试通过；锁定依赖离线安装后确认默认 `flash + geosunpre_native`；
主工程与原生扩展的源码包、wheel 均构建成功。源码包包含正式配置、验证摘要、原生说明及许可证，
不包含重复 fast 配置、本地索引、运行数据或原生构建目录。
真实第二轮/第三轮冻结配置分别读取为 math / flash，保持原后端。
