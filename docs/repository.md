## 配置与恢复

- 新配置版本为 2，默认 `matcher_attention = "flash"`。
- 版本 1 未包含后端字段的冻结配置按 `math` 读取；显式指定的 `flash` 继续生效。
- 保存相同配置不改写旧文件，避免连带改变下游身份。
- 旧目录续跑省略 `--config`；采用新默认时使用新 `--work`。
- Flash 与 math 不共享匹配缓存；原始特征的计算与身份保持一致。
- 原生模块缺失时默认报错；诊断后端的显式选项见 [性能记录](performance.md)。
- GPU 特征缓存默认 2 GiB，且不超过设备显存的 1/8；CPU 后备缓存为 32 张。
  `GEOSUNPRE_GPU_FEATURE_CACHE_MIB` 可调整 GPU 缓存预算，0 表示不保留特征缓存。
  资源优化不新增场景配置字段，不改写已有冻结配置；缓存预算不改变匹配身份。

## 验证范围

本轮资源优化的完整运行峰值 RSS 为 **4.42 GiB**，较此前已提交版本的 5.93 GiB 降低 **25.5%**。
PyTorch 显存峰值没有证明下降；匹配结束后实际分配约 24.4 MiB、保留约 60 MiB。
536 张特征、8,025 对匹配和两套留出集与参考一致，全部注册、0 无效深度、几何门槛和独立导出校验通过。
54 项测试通过。完整记录见 [资源报告](resources.md) 与 [验证摘要](benchmarks/basketball_resources_20260929.json)。

本轮有其他进程同时训练 3DGS，耗时只归档，不用于比较加速或退化。
19 分 51.30 秒是上一轮的历史单次结果，不是当前稳定上限；未验证下游渲染质量。
本次仓库整理保留已完成全量验证的计算代码，不另起完整 GPU 运行。
