# 局部标定消融（2026-09-29）

本报告记录生产/验证模式拆分前的局部标定消融；两臂均有统一留出，现按 validation 续跑。后续生产默认见 [模式说明](production_pipeline.md)。

## 问题与范围

比较两种初始化：正式默认 `calibration_mode = "local"` 先做片段视觉标定；
实验 `calibration_mode = "input"` 直接采用 `.pro` 转换后的内参。两者均继续全局 SfM、
固定内参 BA、轨迹筛选、共享内参 BA、最终 BA 和 COLMAP 导出。
输入模式不是全程固定厂家标定，也不使用 CameraPos 的位姿或 LAS。

实验复用 `work/basketball_resources_20260929_02` 的掩码、536 张特征、8,025 对匹配和两套冻结留出集；
两边在新目录从头计算几何，不复用数据库、标定、位姿、三维点或 BA 结果。
因此是相同观测上的几何消融，不是完整冷启动性能测试或下游 3DGS 验收。
留出观测仍贯穿全部几何阶段排除，不在最终 BA 加回。

## 输入约定核对

当前转换为 `f = focalLength / pixelSize`、`cx = width/2 + principalX/pixelSize`、
`cy = height/2 - principalY/pixelSize`，鱼眼四项取 `k1, k2, k3, p3`。
当前 `.pro` 的哈希及转换结果与参考运行一致。仓库文档和 input 中未找到厂家坐标约定说明，
因此不能把程序内一致性当作厂家约定已经验证；本轮保持解析不变。
详细输入值见实验目录的 `convention_audit.json`。

## 冻结协议

开始几何计算前保存 `protocol.json`，记录源码哈希、前端文件哈希和以下门槛：

- 相同 10,553 个高置信查询，失败预测保留在分母中；不根据两边结果筛选共同成功查询。
- input 相对 local 的 median / P90 增幅不超过 3%。
- 有限预测比例下降不超过 0.5 个百分点。
- 全部 536 张图注册，0 无效深度，点数至少保留 local 的 95%。
- 鱼眼在 160° 内单调，检查内参触界、训练覆盖以及独立导出校验。

工作目录：`work/calibration_ablation_20260929/`，包含 `input/`、`local/` 两个实验臂。
执行顺序是 input 后 local，顺序执行避免两臂争抢资源；单次顺序对照不证明稳定速度收益。
每个阶段独立启动进程，计时包含该进程启动、依赖身份复核和评估开销。
几何耗时为 calibration + sfm + finalize；导出单独报告。

## 使用方式

在新 TOML 中设置：

```toml
expected_images = 536
matcher_attention = "flash"
calibration_mode = "input"
pipeline_mode = "validation"
```

通过正常 `geosunpre run --input ... --work ... --config ... --include-masks` 运行。
输入模式无需可用的局部标定片段；`calibration` 阶段只冻结 input 相机参数及其来源。
正式默认仍为 `local`。配置版本 3 要求保存模式，版本 1/2 的原文件按 local 解释且不改写。
模式改变须使用新目录，校验禁止把已有局部几何重新标记成 input 初始化。

完整实验入口和原始记录保存在上述 work 目录；复用的前端文件仍通过原路径引用，
不可单独搬走工作目录。最终复制模式的 COLMAP 交付包经独立校验后可搬走。

## 完整对照结果

**结论：本轮不采用直接 input 初始化替代局部标定，正式默认保留 local。**

| 指标 | local：保留局部标定 | input：跳过局部标定 |
| --- | ---: | ---: |
| 注册图像 | 536 | 536 |
| 高置信查询数 | 10553 | 10553 |
| median / px | 1.85178 | 1.93212 |
| P90 / px | 6.48477 | 6.61678 |
| 失败预测 | 75 | 72 |
| 稀疏点 | 61753 | 59185 |
| 训练观测 | 390270 | 354382 |
| 每图最少训练观测 | 175 | 171 |
| 每图最少占用 8×8 网格数 | 18 | 15 |
| 几何阶段进程耗时 | 12 分 31.13 秒 | 14 分 16.96 秒 |
| 标定阶段进程耗时 | 0 分 29.94 秒 | 0 分 3.55 秒 |
| SfM 阶段进程耗时 | 11 分 36.43 秒 | 13 分 49.91 秒 |
| 最终阶段进程耗时 | 0 分 24.76 秒 | 0 分 23.50 秒 |
| 导出阶段进程耗时 | 0 分 32.52 秒 | 0 分 28.86 秒 |

两组均有 0 无效深度观测，160° 内鱼眼投影单调，内参未触及边界；
两份复制模式 COLMAP 交付包均通过独立内容校验。
逐项确认轨迹 ID、图像名、特征编号、观测像素完全相同，参考前端文件及运行期间源码哈希未改变。

input 相对 local：median 上升 **4.34%**（约 0.0803 px），超过预设的 3% 门槛；
P90 上升 **2.04%**，有限预测比例提高约 **0.0284 个百分点**，点数保留 **95.84%**。
只有 median 门槛未通过，不能描述为严重重建失败，也不能描述为所有指标都退化。
训练观测减少约 9.20%，最差图像网格覆盖从 18 降至 15；覆盖仍通过原有训练筛选约束。

本轮 input 省下约 26.4 秒标定阶段进程耗时，却增加约 133.5 秒 SfM 阶段耗时，
几何合计增加 **105.83 秒（约 14.1%）**。这是一次顺序执行的复用前端实验，
不是稳定速度结论，不能与 19 分 51 秒完整冷启动记录直接比较。

### 分阶段与内参解释

input 建图时 median / P90 约 2.450 / 8.494 px，轨迹筛选后约 2.333 / 8.326 px，
共享内参 BA 后约 1.932 / 6.617 px。全局内参优化追回了大部分差距，但没有完全达到 local 的结果。

即使跳过局部标定，最终 R 相机主点 cy 仍相对 input 增加 **14.39 px**；
local 流程最终增量为 **17.95 px**。因此不能把差异概括为“input 与视觉标定已经完全一致”。
本轮没有独立标定真值，不能判断这些变化中有多少是厂家参数误差、坐标约定补偿或视觉优化偏差。

### 后续建议

保留局部标定作为当前生产默认；input 模式仅保留为显式实验选项。
局部步骤不是此场景成功建图的必要条件，但本轮对照支持其当前的质量与初始化价值。
若之后仍要取消，先取得设备标定约定说明，并在不同场景验证；不通过调宽本次门槛追认采用。
生产流程与验证流程的拆分可以另行推进，本轮没有取消留出、阶段 BA 或逐阶段评估。
